Sobre mí

Soy desarrollador de software enfocado en aplicaciones de escritorio para pequeños y medianos negocios. Trabajo principalmente con C# y WinForms sobre SQL Server, diseñando el modelo de datos primero y construyendo la interfaz alrededor de él.

Me interesa la parte que casi nadie ve: cómo se relacionan las tablas, qué pasa cuando dos estados chocan, cómo se mantiene consistente un plano visual con lo que hay en la base de datos. Si el sistema se puede vender y mantener, está bien hecho.
